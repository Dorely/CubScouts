# Modular Design Adventure (Elective)

**Official Source**: https://www.scouting.org/cub-scout-adventures/modular-design/

## Snapshot of Adventure
Some of your favorite building toys are probably modular. Learning to build using modular design is a good way to conserve resources. In this Adventure, you will gain an understanding of modular design, build using modular-based materials, and practice making directions for others to follow.

## Requirements

### Requirement 1
Learn what modular design is and identify three things that use modular design in their construction.

### Requirement 2
Using modular-based building pieces, build a model without a set of instructions.

### Requirement 3
Using the model made in requirement 2, create a set of step-by-step instructions on how to make your model.

### Requirement 4
Have someone make your model using your instructions.

### Requirement 5
Using the same modular pieces used in requirement 2, build another model of something different.

### Requirement 6
With your parent or legal guardian's permission, watch a video demonstrating how something was built using modular design.

## Activity Ideas

### Requirement 1 Activities
- **Modular**: Cub Scouts learn concepts of modular design and construction and it benefits.

### Requirement 2 Activities
- **Let's Build It**: Using modular based building pieces Cub Scouts build a model.

### Requirement 3 Activities
- **Draw It Out**: Cub Scouts draw instructions on how to make their design structure.
- **Live Action**: Cub Scouts create video instructions on how to make their design structure.
- **Write It Down**: Cub Scouts write down instructions on how to make their design structure.

### Requirement 4 Activities
- **Following Instructions**: Cub Scouts follow instructions to build a model.

### Requirement 5 Activities
- **My Build**: Cub Scouts design and build a model house of their own imagination or something different.

### Requirement 6 Activities
- **It's Real**: Watch a video of a real-life project that uses modular design.
