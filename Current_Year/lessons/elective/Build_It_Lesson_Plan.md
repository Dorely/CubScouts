# Build It Lesson Plan

## Requirements

- [ ] **1.** Learn about some basic tools and the proper use of each tool. Learn about and understand the need for safety when you work with tools.
- [ ] **2.** Demonstrate how to check for plumb, level, and square when building.
- [ ] **3.** With the guidance of your Webelos den leader, parent, or legal guardian, select a carpentry project that requires it to be either plumb, level, and/or square. Create a list of materials and tools you will need to complete the project.
- [ ] **4.** Build your carpentry project.

## Suggested Lesson Days

Start each den meeting with a **denner-led game** and involve the denner in setup, activities, and closing. Allow 5–10 minutes for the game within the meeting times below.

### Day 1 — Tools and Project Planning

**Approximate time:** 60 minutes · **Requirements:** 1–3

Practice tool use, check plumb/level/square, and choose a project with a materials and tools list.

**Prep and materials:** Bring basic tools, a level, square, plumb line, paper, pencils, and the official project options.

### Day 2 — Build

**Approximate time:** 60–90 minutes · **Requirements:** 4

Build the chosen carpentry project.

**Prep and materials:** Gather lumber, fasteners, tools, and finishing supplies from the Scouts’ lists and the project directions. Prepare stock and workstations and arrange adult help and project transport.

### Family Finish or Second Build Session

**Approximate time:** 30–60 minutes · **Requirements:** 4

Complete assembly or finishing at home with family guidance or at another meeting.

**Prep and materials:** Send home the project directions and remaining supplies, or label and store projects between meetings.

## Suggested Activities by Requirement

**Resources:** [Build It Adventure](../../../reference/Webelos/elective/Build_It_Adventure.md) · [Official adventure and activity directions](https://www.scouting.org/cub-scout-adventures/build-it/)

### Requirement 1

- **Tool Safety and Practice**: Introduce Cub Scouts to basic tools and teach them use the tools safely.

### Requirement 2

- **Doorway Plumb, Level, and Square**: Cub Scouts check a door frame for plumb, level, and square.
- **Table Plumb, Level, and Square**: Cub Scouts check a wooden table for plumb, level, and square.

### Requirement 3

- **Build Project Prep**: Pick a project from the Webelos handbook and put together a list of materials and tools.

### Requirement 4

- **Project Build – Step Stool**: Cub Scouts build a step stool.
- **Project Build – Paper Towel Holder**: Cub Scouts build a paper towel holder.
- **Project Build – Wall Shelf**: Cub Scouts build a wall shelf.
