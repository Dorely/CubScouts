# Build It Lesson Plan

**Rank:** Webelos (Elective) | **Estimated Time:** 2 den meetings × 60 min (+ auxiliary shop overflow as needed) | **Group:** 7–9 scouts, classroom + outdoor flex

> [!IMPORTANT]
> **ADVANCE PREP — READ FIRST**
> **Advanced planning needed? YES — lumber/tools/workspace/safety glasses and build project must be secured before Day 1; auxiliary shop overflow likely.**
> - **Before Meeting 1:** Review `Build It Adventure` reference and Age Appropriate Guidelines for Scouting Activities (tool use). Choose 1–2 build options that are plumb/level/square-dependent and feasible for 7–9 Scouts in 60 min (e.g., step stool, wall shelf, paper towel holder, birdhouse). Confirm workspace: well-ventilated shop/garage or covered tables outdoors with good lighting and flat surfaces. Confirm tool set: hammers, screwdrivers (Phillips/flat), hand saws (leader/adult only if used), sandpaper blocks, tape measures, combination squares, levels (torpedo + 24"), plumb bob or level app, clamps, pencils, and safety glasses for every person. Print tool safety cards, plumb/level/square demo sheets, and Req 3 material-list worksheet. Send parent notice with project preview, safety expectations, and closed-toe shoes requirement.
> - **Before Meeting 2 (Advanced):** **Book these before Day 1 if possible.** Pre-cut lumber to size (leader or hardware store) so Day 2 is assembly-only — confirm bill of materials, cut list, and hardware (screws/nails, wood glue, brackets). Reserve workspace for Day 2 and auxiliary overflow date (same location, 60–90 min). Confirm additional adults — at least 1 per 3 Scouts for tool supervision — and that every adult knows proper use of each tool being used. Sharpen/check tools, charge drills if used by adults only, and stage safety glasses, clamps, and first-aid kit. Check AHMRs and note any restrictions. Stage trash bags and sawdust control.
> - **Shopping & Materials (both meetings):** Safety glasses (12 — one per Scout + adults, ANSI-rated), work gloves (optional, not for power-tool use), tape measures (3), combination squares (3), torpedo levels (3) + 24" level (1–2), plumb bob + string or level app, hammers (3–4), screwdrivers (sets), sandpaper (medium/fine, 12 sheets), clamps (6–8), pencils, project lumber kits (pre-cut per Scout or per pair — e.g., step stool: 4 legs, 2 steps, rails), wood glue, screws/nails, brackets, paper towels, drop cloths, printed tool cards + plumb/level/square posters, material-list worksheets, attendance sheet, first-aid kit. Pre-cut lumber is the biggest time-saver — do not attempt full ripping on den time.
> - **Auxiliary / Pack activity?** **OPTIONAL but EXPECTED overflow.** This plan puts the full build on Day 2; if the project is step stool/shelf, many dens will need a 3rd auxiliary shop day (60–90 min) to finish assembly, sanding, and finishing. State to families up front: Day 2 is primary build; auxiliary shop day is available for completion, make-ups, and applying finish. No pack event needed — den/household shop is appropriate.

## Requirements Checklist

- [ ] **Req 1:** Learn about some basic tools and the proper use of each tool. Learn about and understand the need for safety when you work with tools.
- [ ] **Req 2:** Demonstrate how to check for plumb, level, and square when building.
- [ ] **Req 3:** With the guidance of your Webelos den leader, parent, or legal guardian, select a carpentry project that requires it to be either plumb, level, and/or square. Create a list of materials and tools you will need to complete the project.
- [ ] **Req 4:** Build your carpentry project.

## Day 1 — Tools, Safety & Measure Up (60 min) — Reqs 1, 2, 3 — low-coordination only

*Classroom or covered tables with flat work surfaces. No cutting or assembly. Groups of 3.*

**Opening (5 min)**
Flag, Scout Oath & Law (focus on *obedient* and *clean* — follow safety rules, keep workspace tidy), preview Build It as the carpentry elective. Explain Day 1 = learn tools and measuring, Day 2 = build the project (with auxiliary overflow if needed). Closed-toe shoes and safety glasses rule begins today.

**Activity 1 — Tool Safety and Practice (25 min) — Req 1**
- *Basic Tools Overview (12 min):* At 3 stations, Scouts handle (not yet build) — Station A: hammer + nails (grip, striking, nail set), Station B: screwdriver + screws (pilot hole, clockwise, pressure), Station C: tape measure + square + level + sandpaper. Each station card shows proper use and safety (carry tip down, clamp work, safety glasses on, keep hands clear, ask before swapping tools). Leader demos each, adults supervise.
- *Safety Pledge (5 min):* As a den, name why safety matters (eyes, fingers, bystanders) and list 5 rules on poster: glasses always, clamp first, keep hands behind cutting line, one tool user at a time, put tools down safely. Each Scout states one rule aloud.
- *Hands-On Check (8 min):* Groups of 3 rotate quickly back through stations for one supervised rep — tap a nail into scrap, drive a screw into pre-drilled scrap, measure and sand. Adults correct grip and stance. Completes Req 1 — each Scout has learned basic use and safety for at least 4 tools.

**Activity 2 — Plumb, Level & Square (15 min) — Req 2**
- *Doorway/Table Demo (7 min):* Show what each term means — **Plumb** = vertical true (plumb bob or level on side), **Level** = horizontal true (level bubble centered), **Square** = 90° corner (combination square or 3-4-5 check). Demo on a door frame (plumb), tabletop (level), and box corner (square) using real tools.
- *Scout Try (8 min):* Teams of 3 check 3 objects — door frame for plumb, table for level, and a wooden tray/box for square. Each Scout reads a level bubble and checks a corner with a square, calling out "plumb / level / square / not yet." Leader verifies each Scout demonstrated all three checks. Completes Req 2.

**Activity 3 — Choose the Project & List It Out (10 min) — Req 3**
- *Project Options (5 min):* Present 2 leader-approved choices that require plumb/level/square (e.g., step stool — must be level and square; wall shelf — must be level and square; birdhouse — plumb sides). Show finished examples and effort/time.
- *List Build (5 min):* Den selects one project (majority, leader ties to plumb/level/square need). In teams of 3, Scouts fill out material/tool list worksheet — lumber sizes, hardware, and tools from today's stations. Combine into den master list. Each Scout copies the list to take home. Completes Req 3 with leader/parent guidance.

**Closing (5 min)**
Recap tools, safety pledge, and plumb/level/square. Preview Day 2 build — bring safety glasses if issued, wear closed-toe shoes, expect hands-on rotation. Confirm auxiliary overflow date and that pre-cut kits will be ready. Collect worksheets for lumber purchasing.

## Day 2 — Build Day (60 min) — Advanced / coordinated requirements HERE

*Workshop, garage, or covered tables with drop cloths. Adults 1:3. Pre-cut kits staged. Safety glasses on the entire time.*

**Opening (5 min)**
Safety glasses distribution and fit check, review 5 safety rules and clamping procedure. Show build steps on poster (1. layout & mark, 2. dry-fit & check square/level, 3. glue/screw/nail, 4. check plumb/level again, 5. sand). Assign build teams of 3 with one adult coach each.

**Activity 1 — Assembly Rotation (45 min) — Req 4**
Rotate by build step in teams of 3 with adult coaching — each team works on one project kit (per Scout or per pair depending on budget; per-pair is fine if each Scout does measurable work):
- *Steps 1–2: Layout & Square Check (15 min):* Teams lay out pre-cut parts, mark with square and tape, dry-fit without fasteners, and check for square (diagonals equal) and level (set on flat table, level across top). Adjust before fastening.
- *Step 3: Fasten (20 min):* Adults supervise nailing/screwing — Scouts handle hammers/screwdrivers, adults assist with alignment and clamping; no power tools in Scout hands. One tool user at a time per team. Leader verifies each Scout drives at least 2 fasteners and applies glue where called for. Re-check square/level after each joint.
- *Steps 4–5: True-Up & Sand (10 min):* Final plumb/level/square check — project must sit level without rocking and corners must be square. Scouts sand edges and surfaces with medium then fine grit. Leader initials each project as plumb/level/square-verified.

If a project finishes early, start finish coat (wipe-on) or add personalization (pencil name/date). If time runs short, flag for auxiliary completion rather than rushing fasteners.

**Closing (5 min)**
Display finished/in-progress projects on level table — wobble test and square check as a den. Recap what made it plumb/level/square and which tools were essential. Thank adult coaches and explain auxiliary shop day for final assembly, sanding, and finish. Remind Scouts to keep projects dry until finish cures.

## Auxiliary Day (if needed)

**Auxiliary Shop Overflow (60–90 min) — OPTIONAL but EXPECTED for full completion and make-ups.**

Schedule within one week of Day 2 at the same workspace with the same tool and safety setup. Use it to: complete any unfinished assembly, re-check plumb/level/square, finish sanding, apply second finish coat, and let Scouts who missed Day 2 build their kit with 1:3 coaching. Keep groups of 3 and one-tool-user rule; adults only for any power-tool steps. This day is not a separate adventure — it simply gives Req 4 the time carpentry actually needs without compressing safety checks. No pack activity needed.

## Materials Summary

Safety glasses (12), drop cloths, tape measures (3), combination squares (3), torpedo + 24" levels, plumb bob/string, hammers (3–4), screwdrivers, sandpaper (medium/fine), clamps (6–8), pencils, pre-cut lumber kits + hardware (screws/nails, wood glue, brackets), paper towels, trash bags, tool safety cards, plumb/level/square posters, material-list worksheets, attendance sheet, first-aid kit. Optional finish: wipe-on poly or paint + applicators if project calls for it.

## Safety Notes

Use Scouting America SAFE Checklist at every meeting. Review Guide to Safe Scouting and Age-Appropriate Guidelines for Scouting Activities — Cub Scouts may use common craft tools (hammers, screwdrivers, hand sanding); know each tool's proper use and supervise continuously. Provide safety glasses for every person when tools are in use, clamp work before hammering/screwing, and enforce one tool user at a time with hands clear of striking/fastening zones. Adults handle any sharp cutting or power tools; Scouts do hammering/screwing/sanding only on pre-cut stock. Keep workspace tidy, well-lit, and ventilated; tie back loose clothing/hair and require closed-toe shoes. Follow manufacturer's literature and the most restrictive guideline if conflicts arise. Have a first-aid kit and incident plan on hand; check AHMRs.
