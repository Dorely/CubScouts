# Yo-Yo Lesson Plan

**Rank:** Webelos (Elective) | **Estimated Time:** 2 den meetings × 60 min | **Group:** 7–9 scouts, classroom + open floor

> [!IMPORTANT]
> **ADVANCE PREP — READ FIRST**
>
> **Advanced planning needed? NO — supplies only.**
> - **Before Meeting 1:** Bulk-purchase yo-yos — **one responsive yo-yo per Scout + 2–3 spares + 10 extra strings**. Use fixed-axle or beginner responsive yo-yos (not unresponsive). Print safety-rules sheet, string-length measurement guide, slip-knot diagram, and pendulum worksheet. Confirm facility has **clear throwing space** — 6 ft per Scout, no bystanders, breakables moved, carpet or tape marks optional.
> - **Before Meeting 2:** Gather same yo-yos + extra strings; stage trick cue cards (gravity pull, sleeper, breakaway) with diagrams. No booking, guest, or venue permit needed.
> - **Shopping & Materials (both meetings):** Responsive yo-yos (9 + spares), replacement strings (10+), scissors, string-length ruler/tape, safety-rules poster, slip-knot diagram, pendulum worksheet (pendulum experiment), marker tape for throwing stations, attendance sheet. Optional: small prizes for attempts (not contests).
> - **Auxiliary / Pack activity?** **None needed — fully den-based.** No pack event, hike, campout, or pool required. Two den meetings complete all 7 requirements. If space is tight, use outdoor flex for throwing.
> - **Reference:** `../../reference/Webelos/elective/Yo_Yo_Adventure.md`

## Requirements Checklist

- [ ] **Req 1:** Learn the safety rules of using a yo-yo and always follow them.
- [ ] **Req 2:** Discover how to find the proper yo-yo string length for you.
- [ ] **Req 3:** Explain why it is important to have the correct string length and to be in the right location before throwing a yo-yo.
- [ ] **Req 4:** Demonstrate how to properly string a yo-yo and how to create a slip knot.
- [ ] **Req 5:** Conduct the pendulum experiment with a yo-yo. Explain what happens to the yo-yo when the string is longer.
- [ ] **Req 6:** Show that you can properly wind a yo-yo.
- [ ] **Req 7:** Attempt each of the following: gravity pull, sleeper, breakaway.

## Day 1 — Safety, String & Pendulum (60 min) — Req 1–5

*Classroom with open floor. No tricks yet beyond winding.*

**Opening (5 min)** — Flag, Oath & Law (courteous = watch your space). Preview Yo-Yo as the hand-skill elective. Explain today's safety-first structure; trick attempts are Day 2.

**Activity 1 — Yo-Yo Safety + String Length (20 min) — Req 1, 2, 3**
- *Safety Rules (8 min):* Post rules — check string for fray, check space (arm's length + yo-yo radius, no people in throw zone), throw over soft floor, never walk while throwing, stop if string knots. Each Scout states one rule aloud. Leader models unsafe vs. safe stance.
- *Find Proper Length (12 min):* Demo: hold yo-yo at belly button, string to floor — correct length is floor to belly or 2–4 inches above. Too long = hits floor; too short = weak throw. Each Scout measures and trims/ties to length (leader cuts, Scouts observe). Ask: *Why correct length before throwing?* — control, safety, clean return. Combine Q&A to cover Req 3 (explain importance of correct length + right location). Check off Req 1, 2, 3 when each Scout is at correct length and in a marked throwing station.

**Activity 2 — String a Yo-Yo + Slip Knot (15 min) — Req 4**
- Demo (5 min): Unstring, thread axle, tie loop. Make **slip knot**: make loop, pull string through, slide onto middle finger at first knuckle, snug but not tight, string over knuckle toward throw hand.
- Practice (10 min): In pairs, each Scout strings their yo-yo and makes a slip knot on their throw-hand middle finger, partner checks. Leader verifies. Time-saver: pre-string 2 spares for quick demo. Completes Req 4.

**Activity 3 — Pendulum Experiment (15 min) — Req 5**
- *Swinging* (pairs, 10 min): Fix yo-yo as pendulum (hold string top, not throw). Each pair tests 3 lengths — short, medium, long — count swings in 15 seconds. Record on worksheet. Observe: longer string = slower swing, longer period.
- *Explain (5 min):* Each Scout states what happens when string is longer (slower/longer swing). Connect to throwing: longer string changes timing of return. Completes Req 5.

**Closing (5 min)** — Practice winding correctly (wrap around axle, not knotted) — preview for Day 2. Collect yo-yos or send home with string-length card; remind parents no unsupervised indoor throwing if sent home.

## Day 2 — Wind & Throw: Three Tricks (60 min) — Req 6–7, advanced attempts here but no external booking

*Same open floor. Helmets not needed but clear space mandatory.*

**Opening (5 min)** — Recap safety + string length + slip knot. Re-check throwing stations (6 ft spacing, facing same direction, soft floor). Review winding.

**Activity 1 — Wind a Yo-Yo (10 min) — Req 6**
- Demo: pinch yo-yo, wrap string once around axle by hand, then wind with throw hand while yo-yo is stable — even wraps, no overlap jam. Each Scout shows a proper wind and a smooth return to hand. Leader checks off Req 6 when wind is even and yo-yo returns without hand-winding.

**Activity 2 — Three Trick Attempts (40 min) — Req 7**
- Rotate through 3 stations, ~12 min each, groups of 3 with one adult coach per station. **Attempt, not mastery** — each Scout tries, not required to perfect.
- **Station A — Gravity Pull:** Strong throw down, let spin at bottom, tug to return. Coach checks throw angle (straight down, not forward).
- **Station B — Sleeper:** Throw hard, let yo-yo sleep (spin at bottom without immediate return), flick wrist to wake and return. Count seconds of sleep.
- **Station C — Breakaway:** Swing to side (like pendulum to 3 o'clock), release forward, let swing back and return — the "side throw." Emphasize side clearance.
- Each Scout attempts each trick twice; coach initials attempt card for each. Completes Req 7 when all three have been attempted (not judged on quality). Celebrate attempts, not rankings.

**Closing (5 min)** — Circle: which trick was hardest? Which safety rule mattered most today? Collect yo-yos or allow take-home with parent note. Photo of group with yo-yos for pack newsletter.

## Materials Summary

Responsive yo-yos (9 + spares) + 10 extra strings, scissors, tape/markers for stations, safety poster, string-length guide, slip-knot diagram, pendulum worksheet, trick cue cards, attempt cards, attendance sheet.

## Safety Notes

SAFE Checklist; clear throwing zones (6 ft per Scout, no bystanders, soft floor); inspect strings for fray/knots before each throw; stop if yo-yo wobbles or string frays; no walking while throwing; adult supervision at each station; keep spare strings handy.
